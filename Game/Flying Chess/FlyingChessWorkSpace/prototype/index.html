飞行棋 · 骰子样式候选

服务端定结果，客户端只播放预设动画并停在该点数；无物理模拟。以下四种为同一几何的材质差异，第四种为 WebGL 不可用时的降级方案。

A · 象牙
暖白骰身、炭黑点。最耐看，四种阵营色在它旁边都不打架。
推荐
B · 墨石
深灰骰身、象牙点。中央深色块能压住棋盘，骰子更突出。
C · 瓷白描边
近白骰身、每面一圈细描边。最轻，接近纸面质感。
D · 降级（CSS 3D）
无 WebGL 或用户要求减少动态时使用。点数与规则完全一致。
棋盘底色取自已生成的 SVG（#fff 底、#22222a 描边、四色 #1fa84a / #e02b2b / #f6d11a / #1d6fd6）。
